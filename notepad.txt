# Xây dựng Web App Food Delivery giống GrabFood

Hãy xây dựng một web app đặt món ăn cơ bản lấy cảm hứng từ GrabFood, tập trung vào UI/UX hiện đại, sạch sẽ, responsive và dễ sử dụng.

## 1. Công nghệ bắt buộc

Chỉ sử dụng:

* HTML5
* JavaScript ES6+ / Vanilla JavaScript
* TailwindCSS
* `localStorage` để lưu dữ liệu phía client
* `db.js` làm nơi quản lý dữ liệu mock và export/import dữ liệu

Không sử dụng:

* React
* Vue
* Angular
* Next.js
* Node.js backend
* Database server
* TypeScript
* jQuery
* Bootstrap
* Framework frontend khác

Có thể sử dụng TailwindCSS CDN để đơn giản hóa việc chạy project.

## 3. Database mock

Tạo file:

```text
js/db.js
```

File này chứa toàn bộ dữ liệu mock và phải sử dụng ES Module:

```js
export const products = [...]
export const reviews = [...]
export const categories = [...]
```

Các file khác import dữ liệu từ `db.js` bằng:

```js
import { products, reviews, categories } from './db.js';
```

Có ít nhất 15 món ăn.

Mỗi món cần có:

```js
{
  id,
  name,
  description,
  price,
  image,
  category,
  rating,
  reviewCount,
  restaurant,
  preparationTime
}
```

Tạo khoảng 5-6 category, ví dụ:

* Cơm
* Mì
* Burger
* Pizza
* Gà
* Đồ uống

15 món ăn phải phân bố tương đối đều giữa các category.

Có thể sử dụng ảnh món ăn từ nguồn ảnh public phù hợp. Nếu dùng URL ảnh thì đảm bảo ảnh có thể hiển thị trực tiếp trên browser.

## 4. Reviews

Tạo sẵn khoảng 2-3 review mẫu.

Không cần tạo 2-3 review riêng biệt cho từng món. Có thể sử dụng một nhóm review mẫu và hiển thị chúng cho các món khác nhau.

Review có cấu trúc:

```js
{
  id,
  productId,
  userName,
  rating,
  comment,
  date
}
```

Người dùng có thể tự đánh giá món ăn.

Khi submit review:

1. Kiểm tra rating.
2. Kiểm tra nội dung review.
3. Lưu review vào `localStorage`.
4. Cập nhật UI ngay lập tức.
5. Tính lại rating trung bình của món ăn.

Không cần backend.

## 5. localStorage

Sử dụng `localStorage` để quản lý:

```text
cart
reviews
user
orders
```

Ví dụ:

```js
localStorage.setItem('cart', JSON.stringify(cart));
```

Tạo các helper function dùng chung để:

* getCart()
* saveCart()
* addToCart()
* removeFromCart()
* updateCartQuantity()
* clearCart()
* getReviews()
* saveReview()
* getOrders()
* saveOrder()

Không lặp lại logic localStorage ở quá nhiều file.

* TailwindCSS
* Rounded cards
* Soft shadow
* Clean spacing
* Modern typography
* Food images lớn
* Button rõ ràng
* Badge

* Hover animation

Primary: orange/red

## 15. Code architecture

Ưu tiên code modular.

Ví dụ `app.js`:

```js
export function getCart() {}
export function saveCart(cart) {}
export function addToCart(product, quantity = 1) {}
export function removeFromCart(productId) {}
export function updateCartQuantity(productId, quantity) {}
export function updateCartBadge() {}
export function showToast(message, type = 'success') {}
export function formatCurrency(price) {}
```

Không viết toàn bộ project thành một file JavaScript duy nhất.

Sử dụng:

```js
import
export
async/await
const
let
template literals
optional chaining
destructuring
```

khi phù hợp.

## 16. Error handling

Phải xử lý:

* Product không tồn tại
* URL không có product ID
* Cart rỗng
* localStorage bị lỗi
* Review không hợp lệ
* Checkout thiếu thông tin
* Số lượng sản phẩm nhỏ hơn 1

Nếu product không tồn tại:

```text
Product not found
[ Back to Products ]
```

## 17. Currency

Sử dụng tiền Việt Nam:

```text
25.000 ₫
45.000 ₫
```

Tạo helper:

```js
formatCurrency(price)
```

để format thống nhất toàn bộ app.

## 18. Seed data

Khi app chạy lần đầu, nếu localStorage chưa có dữ liệu review/cart thì khởi tạo dữ liệu mặc định từ `db.js`.

Không được overwrite dữ liệu người dùng ở những lần reload tiếp theo.

## 19. Accessibility

Đảm bảo:

* button có text rõ ràng
* input có label
* image có alt
* màu chữ đủ tương phản
* focus state rõ ràng
* keyboard navigation cơ bản

```js

```

Cuối cùng, cung cấp hướng dẫn ngắn gọn:

1. Cách chạy project bằng VS Code + Live Server.

3. Mô tả ngắn kiến trúc project.
4. Liệt kê các tính năng đã hoàn thành.

Ưu tiên chất lượng UI/UX và tính hoàn chỉnh của ứng dụng hơn việc viết code ngắn.
